## 0. 三条总原则（贯穿全文）

1. **姿态固定比事后建模可靠**——参考论文的核心结论之一：不建模复杂反射，而是用定位码把拍摄姿态约束到标准状态，让反射条件一致。
2. **校正基准必须实测，不能用设计色**——打印机存在色彩失真，参考色块的"标准 RGB"必须来自每批印刷成品的实测标定，否则校正基准本身就是错的。
3. **AI 只输出读数**——颜色识别只负责"把试纸颜色翻译成数值"，限值判断、组合诊断、处置建议仍由后端 GB/T 1576 规则引擎负责（既有架构不变，识别模块是可插拔的前置环节）。

## 1. 总体链路

```
现场放试纸 → 小程序引导拍照(姿态约束+自动快门) → 服务端质量门禁(已有) → ArUco 定位拉正(1600×1100)
→ 光照不均校验(左右灰阶对比) → 颜色校正(参考色块/渐变条) → 8 槽位 ROI 取色
→ CIE xy 色度空间读数(参考曲线+IDW插值) → 置信度评估 → AI建议值+人工确认
→ 确认值交规则引擎(限值判定/组合诊断/复测闭环，现有逻辑不变)
```

每一步的产物（照片、拉正图、校正值、AI 值、确认值）都落库，与既有"识别样本审核"流程衔接，人工值/AI 值/确认值分别保存、禁止覆盖。

## 2. 操作台比色卡纸设计

### 2.1 V1（已落地，继续作为灰测用版）

`test-strip-board/` 已生成，规格不再重复（A4 横向、四角 ArUco DICT_4X4_50 码 ID 0-3、8 槽位、左右对称 5 级灰阶 ×2、底部 6 基础色 + 3 试纸定制色、50mm 标尺）。

**V1 必须补做的一件事：批次实测标定。**
`board_layout.json` 里目前存的是设计 RGB，只能用于调试。正式用于颜色校正前：

1. 每批打印稿随机抽 3–5 张，用扫描仪或标准光源下的固定相机拍摄；
2. 按固定坐标取 14 个色块的实测 RGB，取均值作为该批次"标定参考值"入库（新表或配置 JSON，字段：批次号、色块名、实测 RGB、标定日期、标定设备）；
3. 材料包与打印稿批次绑定，识别时按批次取参考值。

### 2.2 V2（参照论文的演进版，随算法 P1 阶段同步改版）

参考论文的参考板不是离散色块，而是**四边 HSV 连续渐变色条**（顶/底 Hue 渐变、左侧 Saturation 渐变、右侧 Value 渐变），全板采样约 424 对观测点，这是空间变系数校正（SVCM）的数据基础。我们 14 个离散点撑不起这个模型，V2 改版要点：

| 区域 | 设计 |
|---|---|
| 四角 | ArUco 定位码不变（ID 0-3、30×30mm、5mm 静区），姿态解算与拉正逻辑完全复用 |
| 四边 | 新增连续渐变色条：顶边/底边 Hue 0–360° 渐变，左边 Saturation 渐变，右边 Value 渐变；条宽 8–10mm，与槽位区、定位码静区间隔 ≥5mm |
| 中部 | 8 槽位布局不变（坐标已写死，尽量保持兼容；若必须移动，改版时同步更新 `board_layout.json` 并升版本号） |
| 左右 | 对称灰阶保留（SVCM 的左右对照点 + 光照不均检测指标） |
| 底部 | 基础色块压缩为一排小色块或并入渐变条；3 个试纸定制色保留（试纸黄/试纸绿/钼蓝，按实际试纸品牌批次显色标定后修订） |
| 标尺 | 50mm 标尺保留，打印缩放核对用 |

**版式兼容性原则**：`generate_board.py` 出 V2 稿时 `layout_version` 升 2，拉正目标尺寸仍 1600×1100，算法按版号取坐标集，新旧两版打印稿在过渡期都可识别。

### 2.3 物理工艺要求

- 哑光覆膜或不覆膜（**覆膜会引入镜面反光，需实物验证后决定**，见 §7 风险 1）；
- 300g 以上铜版纸或 PVC 板，保证平整不卷边；
- 打印必须 100% 实际大小，50mm 标尺验收；
- 每批次留样 3 张用于实测标定，批次号喷码在板背面（正面定位码静区内禁止任何印刷）。

## 3. 拍照逻辑

### 3.1 拍摄姿态约束（小程序端实时引导）

4 个 ArUco 码的 16 个角点即 PnP 位姿解算的全部输入，无需新增硬件。小程序端（或拍照后即时上传服务端快检）做三件事：

1. **取景框引导**：屏幕显示操作台轮廓框，提示"将四个定位码对准框内"；
2. **姿态解算**（每帧）：
   - 由 4 码中心在画面中的位置解算单应矩阵 H；
   - 由 H 分解（或 PnP）得俯仰角 θ 与拍摄距离 d；
   - 距离换算参考论文相似三角形公式：`d = H_ref × (板物理宽 / 板成像宽)`，H_ref 为标定参考距离；
3. **达标自动快门**（容差为初版建议值，待实物验证后调整）：

| 约束项 | 建议容差 | 依据 |
|---|---|---|
| 俯仰角 | 90° ± 10°（正俯视） | 论文结论 90° 最优；±10° 为工程放宽，需实物验证（§7 风险 1） |
| 拍摄距离 | 最优距离的 1.0–1.5 倍 | 论文容差区间 |
| 水平偏移 | 板中心偏离画面中心 ≤ 20px（1080p 等效） | 论文容差 |
| 定位码成像宽度 | ≥100px / 码 | 操作台 V1 设计约束，低于则提示"靠近一点" |
| 画面稳定 | 连续 3 帧位移 < 阈值（防手抖糊片） | 工程自加 |

达标后自动拍摄（用户也可手动触发，但不达标需二次确认）。**45° 斜拍等非常规姿态直接拦截**，不进入识别。

### 3.2 环境与操作要求（沿用既有 §6.1 采集要求并强化）

- 均匀白光，避免彩色光源；禁止闪光灯直射（参考论文实测闪光灯差分法误差大，mRMSE 67.86，不采用该路线）；
- 避免镜面反光、蒸汽、水雾；试纸按说明书显色时间到点后 **5 分钟内完成拍摄**（显色漂移是读数系统性误差来源，需按品牌实测漂移曲线，见 §7 风险 4）；
- 同一材料包批次尽量固定拍摄背景流程。

### 3.3 服务端复检（拍照后的第二道闸）

上传后依次执行：

1. **既有基础质量门禁**（格式/大小/短边≥720px/亮度/对比度/清晰度 → pass/review/reject，逻辑不变）；
2. **定位码复检**：4 码齐全、ID 正确、码宽 ≥100px——缺一即 reject 重拍（拉正的前提，没有商量余地）；
3. **光照不均指标**：拉正后取左右两组 5 级灰阶实测 RGB，逐档计算左右差 Δ：
   - `Δ_gray = mean(|RGB_left - RGB_right|)` 跨 5 档取平均；
   - 阈值建议：`Δ_gray ≤ 8` 通过，`8–15` 进入 review（可继续但标记），`> 15` reject 提示"换个光线均匀的位置重拍"（**阈值为占位初值，需用灰测实拍数据标定**）。

## 4. 识别算法（后端 pipeline）

前置说明：分两个阶段演进，**V1 算法用现有 V1 操作台即可跑通闭环**，V2 算法随 V2 操作台上线升级，两者共用同一条 pipeline 骨架，只是校正模型和参考数据升级。

### Step 1 定位拉正（已实现）

`test-strip-board/rectify.py`：检测 4 码 → 码中心做单应变换 → 1600×1100 固定图。所有后续坐标写死在 `board_layout.json`。

### Step 2 光照不均校验

即 §3.3 第 3 条的左右灰阶对比，不通过则终止并返回重拍提示。

### Step 3 颜色校正

**V1：全局线性校正（14 个离散色块）**

对每个通道 c ∈ {R, G, B}，用 14 个色块的"实测值 xᵢ（本照片）→ 标定值 yᵢ（批次标定库）"做最小二乘拟合：

```
y = αc · x + βc        （每通道 2 个参数，14 个样本点 OLS）
```

逐槽位 ROI 应用同一组 (αc, βc)。局限：假设失真全板一致，光照不均场景残余误差大——这正是 V2 要解决的。

**V2：空间变系数校正 SVCM（论文核心方法，照搬）**

系数本身随位置变化，建模为一阶空间曲面：

```
R'(x,y) = αr(x,y)·R(x,y) + βr(x,y)
αr(x,y) = a0 + a1·x + a2·y
βr(x,y) = b0 + b1·x + b2·y
G、B 通道同理，共 3 通道 × 2 曲面 × 3 系数 = 18 个参数
```

训练数据：在 V2 操作台四边渐变条上每 10px 采样一对（实测 RGB, 标定 RGB），约 400+ 对观测，对每个系数曲面做 OLS。校正时对每个槽位 ROI 按其中心坐标 (x,y) 取系数。

参考论文效果：校正后颜色方差最多缩小约 15 倍（注意：论文摘要写"90%"，正文图注为 15 倍，以正文为准）；均匀光照下 SVCM 相比离散色卡全局校正优势很小（mRMSE 13.41 vs 13.93），**它的价值恰好在光照不均场景——也就是我们锅炉房现场的主要场景**，路线成立。

### Step 4 槽位 ROI 取色

- 按 `board_layout.json` 固定坐标裁 8 个槽位；
- 槽内定位试纸反应区：试纸为浅色长条上的显色斑块，用饱和度/色相突变分割，取反应区中心 60% 区域；
- 取色用**中位数**而非均值（抗反光亮点、指纹、水渍等异常像素），再剔除距离中位数 >2σ 的离群像素后取均值作为最终 RGB；
- 若反应区分割失败（试纸放歪、未显色、槽位空缺），该项标记 `recognition_failed`，进入人工录入。

### Step 5 读数解算（CIE xy 色度空间 + 参考曲线插值）

1. 校正后 RGB → CIE 1931 XYZ（标准 sRGB 转换矩阵）→ 色度坐标 (x, y)；
2. 每个指标（pH、磷酸根……）× 试纸品牌批次，预先建"参考曲线"：用梯度浓度标准溶液（如 pH 4/6/7/9/10 缓冲液）点样试纸，标准姿态拍摄走完整 pipeline，记录各档 (x, y) 坐标——即该指标的**比色锚点序列**；
3. 实测 (x, y) 在锚点序列上找最近两档，**反距离加权（IDW）插值**出连续读数：

```
v = (v1/d1 + v2/d2) / (1/d1 + 1/d2)，d 为 xy 平面欧氏距离
```

4. 若最近锚点距离超过阈值（颜色落在参考曲线可达范围外），判为异常显色，置信度归零转人工。

参考论文用此方法 pH 读数 MAE 0.12，同期人眼读数 MAE 0.37，约为肉眼 3 倍精度。
备选：Lab 空间的 ΔE 最近邻可作为对照组同步跑，用灰测数据比较后再定主算法。

### Step 6 置信度与人工确认

置信度为综合分（各项 0–1 取最小值或加权）：

| 因子 | 说明 |
|---|---|
| 姿态分 | 拍照时记录的俯仰角/距离达标程度 |
| 光照分 | 左右灰阶差 Δ_gray 归一化 |
| 校正残差 | 色块校正后的平均残差（校正模型自身的拟合优度） |
| 锚点距离 | 实测色度到最近锚点的距离归一化 |
| 显色时间 | 距标准显色时间的偏移 |

- **P1 阶段（半自动）**：AI 值全部作为"建议值"预填进小程序 8 项录入框，人工逐项确认/修改后提交——交互改动小，且天然持续产出"AI 值 vs 确认值"配对数据；
- **P2 阶段（自动）**：置信度 ≥ 阈值的项目自动采用，低于阈值的才打断人工确认；阈值按"高风险漏报率"反推（见 §6）。

### Step 7 交规则引擎

确认后的 8 项数值走现有 `/inspections/recognize` 逻辑：压力段限值匹配、5 类组合诊断、评分、复测任务。**识别侧的任何改动都不触碰这一层。**

## 5. 标定体系（三件事，缺一不可）

| 标定对象 | 方法 | 频率 |
|---|---|---|
| 打印稿批次 | 抽 3–5 张标准条件实测 14 个色块 RGB 入库（V2 为渐变条密集采样） | 每印刷批次一次 |
| 试纸品牌批次 | 梯度标准溶液点样 → 标准姿态拍照 → 建 CIE xy 锚点序列（每指标 ≥5 档） | 每试纸批次一次 |
| 手机设备差异 | 论文方案理论上设备无关（校正吸收设备差异），但需用 3–5 台不同档位手机实测验证 | 算法上线前一次 + 每年抽检 |

## 6. 精度目标与验收指标

| 指标 | 目标 | 说明 |
|---|---|---|
| pH 读数 MAE | ≤ 0.2 | 论文达到 0.12，我们放宽一档作验收线 |
| 其它 5 项读数 | 相邻色阶命中率 ≥ 90% | 半定量指标按色阶档评估 |
| 高风险漏报率 | 优先控制，目标 0 | 超限被误判正常的比例，宁可误报不可漏报 |
| 重拍率 | ≤ 15% | 姿态/光照拦截导致的重拍，过高说明容差太紧 |
| 人工修改率 | P1 阶段持续监测，降至 < 30% 才考虑升 P2 | AI 建议值被人工改动的比例 |

评估集划分按企业/试纸批次/设备拆分，防止数据泄漏（沿用既有样本审核流程产出的 approved 数据）。

## 7. 风险与待验证清单

1. **俯仰角定稿**：论文"90° 最优"来自朗伯假设仿真。必须用我们的覆膜/不覆膜打印稿 + 真实试纸做 90° vs 60° vs 45° 实物扫描对比，再定容差。
2. **覆膜反光**：哑光膜是否足以避免镜面反射亮斑，未定；不行则不覆膜改耐污工艺。
3. **闪光灯路线已排除**：参考论文实测闪光灯差分法（Nixon 法）误差大且依赖双图对齐，不采用；现场光线不足时引导用户开常亮补光而非闪光灯。
4. **显色时间漂移**：各品牌试纸显色后颜色随时间漂移，需实测漂移曲线确定"可拍摄窗口"，并在置信度中计入。
5. **打印批次管理**：标定值与批次绑定，若现场混用不同批次操作台，识别需先识别版号/批次（板面角落加批次二维码，V2 加入，避开定位码静区）。
6. **论文口径注意**：摘要"方差降 90%"与正文"15 倍"不一致，以正文为准；均匀光照下 SVCM 优势很小，我们的收益预期应锚定在光照不均场景。

## 8. 实施路线

| 阶段 | 内容 | 退出标准 |
|---|---|---|
| P0（现状） | V1 操作台打印投入使用；人工读数；照片拉正留样；样本审核产出训练集 | 积累 ≥500 张 approved 配对样本 |
| P0.5 | 打印稿批次实测标定流程建立；服务端定位码复检 + 光照不均指标上线 | 重拍拦截链路可用 |
| P1 | V1 全局线性校正 + CIE xy 读数上线，"AI 建议值 + 人工确认"；小程序姿态引导上线；同步完成试纸批次锚点标定 | 人工修改率、MAE 达标；V2 操作台设计定稿 |
| P2 | V2 操作台 + SVCM 上线；高置信项目免确认；按批次/设备灰度发布 | 高风险漏报率 ≈ 0，人工修改率 < 30% |
