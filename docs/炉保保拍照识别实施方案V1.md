# 炉保保试纸拍照识别实施方案 V1

版本：V1.0 评审稿
日期：2026-08-07
适用阶段：操作台打样、算法原型、小程序灰测

## 1. 最终建议

炉保保采用“半封闭拍照装置 + 固定槽位操作台 + 同图颜色校准 + 分项目色阶模型 + 人工确认 + 后端规则判断”的路线。

不建议第一版使用一个深度学习模型直接从整张照片输出7项数值。第一版应让传统机器视觉和颜色算法承担主要读数任务，AI模型只辅助完成试纸存在性、污染、反光和异常图像识别。

完整责任边界：

```text
操作台和拍照装置：稳定物理条件
小程序：指导操作、计时、拍照、确认读数
识别服务：定位、颜色校正、候选色阶和置信度
业务后端：标准判断、诊断、处置提醒和复测任务
后台人员：审核低置信度结果和专业处理建议
```

## 2. 检测组合

操作台设置7个正式槽位，不设置预留槽位。

| 槽位 | 水样 | 检测项目 | 是否固定 |
| --- | --- | --- | --- |
| S1 | 软化水 | pH | 固定 |
| S2 | 软化水 | 硬度 | 固定 |
| B1 | 炉水 | pH | 固定 |
| B2 | 炉水 | 总碱度 | 固定 |
| B3 | 炉水 | 氯离子 | 建议启用，作为浓缩趋势辅助 |
| B4 | 炉水 | 磷酸根 | 使用磷酸盐药剂时启用 |
| B5 | 炉水 | 亚硫酸根 | 使用亚硫酸盐除氧剂时启用 |
炉水硬度不作为日常固定项目。电导率或TDS作为后续仪表项目预留，不强行用普通颜色试纸替代。

锅炉档案必须记录磷酸根和亚硫酸根的启用状态：`enabled`、`disabled`、`unknown`。状态不明确时允许拍照记录，但系统不得把零值直接判断为加药不足。

## 3. 实体产品组成

一套操作台由四部分构成：

1. 哑光硬质底板。
2. 可更换校准卡纸。
3. 可更换湿区试纸托盘。
4. 折叠式拍照罩和固定LED光源。

固定光源是V1的必要组成，不建议完全依赖办公室灯光或自然光。颜色校正可以降低环境差异，但无法可靠恢复已经过曝、强反光或严重偏色的图像。

### 3.1 推荐尺寸

- 底板：A4横向，约297 mm x 210 mm；打样时可放大到320 mm x 230 mm。
- ArUco定位码：30 mm x 30 mm，四周至少5 mm白色静区。
- 试纸槽：7个，槽间距根据最终试纸宽度确定，建议中心距不小于22 mm。
- 连续校准色带：宽度10-12 mm，沿操作台四边布置。
- 离散校准色块：每块不小于10 mm x 10 mm。
- 项目比色块：每块不小于8 mm x 8 mm，与对应试纸显色区相邻但物理隔水。
- 手机拍摄高度：通过样机确定，目标是操作台占原图宽度的70%-85%。

上述尺寸是打样起点，冻结前必须用真实试纸和至少5款手机验证像素占比。

### 3.2 操作台布局

```text
┌──────────────────────────────────────────────────────┐
│ [ID0]   顶部Hue色带 + 离散校准块               [ID1] │
│ S/V色带                                               S/V色带 │
│          S1   S2   B1   B2   B3   B4   B5             │
│          │    │    │    │    │    │    │              │
│          │    │    │    │    │    │    │              │
│        每槽试纸显色区旁设置对应项目的实体比色阶         │
│ [ID2]   底部Hue色带 + 板卡/批次二维码             [ID3] │
└──────────────────────────────────────────────────────┘
```

### 3.3 四角定位

- 使用ArUco `DICT_4X4_50`，四角分别为ID 0、1、2、3。
- 四个定位码不重复，用于判断方向和恢复操作台坐标系。
- 生产识别要求四个码全部出现；三个码仅用于研发容错，不作为正式自动读数条件。
- 定位码与颜色区域保持间隔，不能被试纸、手指、水滴或二维码遮挡。

### 3.4 校准卡纸

校准卡纸同时包含两类参考：

**全局颜色参考**

- 顶部、底部为连续Hue色带。
- 左右为Saturation和Value变化色带。
- 白、浅灰、中灰、深灰、黑。
- 红、绿、蓝、青、品红、黄。
- 针对实际试纸颜色增加若干定制色块。
- 左右设置重复色块，用于检测局部阴影。

**项目局部参考**

- 每个项目旁设置厂家色阶的实体复刻色块。
- 每个色块关联项目、数值、单位、试纸品牌和批次。
- 项目色阶用于局部比较，不能代替真实反应试纸训练数据。

校准卡纸必须可更换，并具有：

- `board_id`；
- `board_version`；
- 生产批次；
- 试纸批次；
- 颜色参考文件版本；
- 启用日期和失效日期。

设计文件的RGB值不能直接作为实体色块真值。正式卡纸应使用色差仪或分光测色仪测量实体色块，连续色带在受控灯箱内数字化，生成该批卡纸的标准参考图。

### 3.5 湿区托盘

- 试纸槽与色卡物理隔离。
- 显色区保持平整，不被夹具遮挡。
- 设置挡水边和独立吸水区。
- 托盘可擦洗或一次性更换。
- 使用中性灰、哑光、耐水材料。
- 禁止光面覆膜、透明胶带和高反光亚克力。

### 3.6 试纸防错标记

试纸手持端增加黑白项目码和方向箭头：

- 固定槽位是项目身份主依据。
- 手持端标记用于检查是否放错试纸。
- 标记远离浸水线和显色区。
- 不使用彩色墨水，避免影响颜色校正。
- 标记由生产端印刷或使用独立夹片，不允许用户手画。

## 4. 折叠拍照罩

V1建议材料包配套一个低成本折叠拍照罩：

- 固定手机与操作台的大致距离。
- 遮挡顶部和侧面杂光。
- 内壁采用中性灰或黑色消光材料。
- 两侧设置高显色指数LED和柔光板。
- 光源不直接照射手机镜头。
- 不使用手机闪光灯作为默认光源。
- 电源和亮度固定，不允许用户调色温。

拍照罩不必做成精密仪器，但应显著减少光照方向、色温和手机角度差异。算法仍使用每张照片内的色带做二次校正。

## 5. 化学操作和统一拍照时间

每种试纸必须建立操作配置：

- 取样点；
- 浸泡或滴加方式；
- 浸泡时间；
- 甩水或吸水方式；
- 显色开始时间；
- 推荐读数时间；
- 最早和最晚有效读数时间；
- 温度范围；
- 常见干扰物。

小程序根据各试纸有效时间窗口倒排操作顺序：

1. 显色时间最长的试纸先操作。
2. 按系统倒计时依次处理其他试纸。
3. 所有启用项目进入共同有效窗口后开放拍照。
4. 任一项目超时则标记无效并要求重做该项目。

如果真实试纸无法形成共同时间窗口，则必须改成两次拍照，不能让算法猜测已经变化的颜色。

## 6. 小程序流程

```text
选择锅炉
→ 读取锅炉药剂方案和必测项目
→ 校验材料包、操作台和试纸批次
→ 显示试纸操作顺序与倒计时
→ 提示放入固定槽位
→ 打开拍照页
→ 对齐取景框并拍照
→ 后端执行质量检查
→ reject则立即重拍
→ pass/review则执行颜色识别
→ 展示候选读数
→ 用户确认
→ 后端分别判断软化水和炉水
```

### 6.1 拍照页面

页面只展示必要信息：

- 操作台对齐框；
- 四角状态；
- 手机移动方向；
- 光照、反光、清晰度提示；
- 缺少或放错试纸提示；
- 统一拍照窗口剩余时间；
- 自动拍照或拍照按钮。

V1可以先采用固定取景框，拍照后由服务器在约2秒内返回质量结果。V1.5再使用小程序相机帧监听实现实时四角和槽位检测。V2根据性能评估接入WASM/OpenCV实现实时ArUco和自动快门。

### 6.2 用户确认

- 高置信度：自动填写第一候选，用户确认。
- 中置信度：显示相邻两个色阶，让用户选择。
- 低置信度：不输出读数，要求重拍或人工比色。
- 用户修改AI结果时必须保存AI原值和人工值。

## 7. 服务端图像处理

服务端使用Python、OpenCV和独立识别服务，主流程如下：

```text
原图解码
→ EXIF方向校正
→ ArUco检测
→ 相机姿态和画面完整性检查
→ 透视校正
→ 操作台版本识别
→ 全局图像质量门禁
→ 颜色校正
→ 槽位与试纸身份检查
→ 试纸显色区提取
→ 分项目色阶识别
→ 置信度计算
→ 返回候选读数
```

### 7.1 质量门禁

**文件级**

- 格式、大小、分辨率和方向合法。
- 没有严重压缩、模糊、过曝或欠曝。

**操作台级**

- 四个ArUco全部识别。
- 四边和连续色带没有被裁切。
- 透视校正后的尺寸比例正确。
- 操作台画面占比和相机角度合格。

**试纸级**

- 必测槽位存在试纸。
- 项目码与槽位一致。
- 试纸没有重叠、反放或严重弯曲。
- 显色区没有大水珠、污染或高光。

**颜色级**

- 白色块未过曝、黑色块未欠曝。
- 左右重复色块差异合格。
- 颜色校正残差合格。
- ROI颜色均匀度合格。

门禁结果：`pass`、`review`、`reject`。`reject`状态后端禁止生成读数。

## 8. 颜色校正算法

采用论文的一阶空间变化系数模型作为V1基线，分别拟合R、G、B通道：

```text
Reference_c(x,y) = alpha_c(x,y) * Image_c(x,y) + beta_c(x,y)

alpha_c(x,y) = a1*x + a2*y + a3
beta_c(x,y)  = b1*x + b2*y + b3
```

执行步骤：

1. 从四边连续色带每隔固定像素采样。
2. 根据卡纸版本获取对应标准颜色。
3. 排除反光、污染和异常采样点。
4. 使用稳健加权最小二乘拟合每个通道的参数。
5. 对裁正后的操作台图像执行空间颜色校正。
6. 用未参与拟合的离散色块做独立验证。
7. 校正残差过大则返回`reject`或`review`。

一阶模型优先于复杂模型，因为样本少、可解释且不容易过拟合。二阶模型或神经网络校正只有在独立验证集显著改善时再启用。

## 9. 显色区提取

透视校正后每个槽位坐标固定：

1. 在槽位范围检测手持端标记和试纸边缘。
2. 根据试纸模板定位显色区。
3. 从显色区边缘向内缩小，避开毛细扩散边缘。
4. 屏蔽高光、水珠、气泡、阴影和污染像素。
5. 把ROI划分为多个子区。
6. 计算颜色中位数、截尾均值和均匀度。
7. 保存ROI图片和颜色特征供后台复核。

不能只读取单个像素，也不能简单使用整个试纸平均RGB。

## 10. 数值识别算法

### 10.1 V1离散色阶

每个项目、每个试纸批次建立独立模型。每个色阶保存：

- 标准溶液真值；
- 真实试纸颜色中心；
- CIELAB、CIE xy、HSV和归一化RGB特征；
- 颜色波动和协方差；
- 相邻色阶决策边界；
- 支持的手机和显色时间范围。

识别时同时计算：

- CIEDE2000色差；
- 马氏距离；
- CIE xy距离；
- 与邻近实体比色阶的相对色差。

输出第一候选、第二候选和候选间隔。V1只输出厂家原有离散色阶，不制造超出试纸能力的小数精度。

### 10.2 后续连续插值

仅在某项目满足以下条件时启用：

- 颜色随浓度呈稳定单调轨迹；
- 标准溶液覆盖色阶之间的中间点；
- 多批次、多手机、多时间点验证通过；
- 相对于参考方法具有明确误差；
- 页面展示不确定度。

满足条件后可参考论文，在CIE xy或验证更优的颜色空间中，对最近两个色阶执行反距离加权插值。

## 11. 置信度

```text
置信度 = F(
  四角定位质量,
  拍摄姿态,
  全图质量,
  颜色校正残差,
  试纸身份,
  显色区均匀度,
  显色时间,
  批次匹配,
  第一与第二候选间隔
)
```

初始分级：

- 高：自动填写并由用户确认。
- 中：显示两个候选。
- 低：禁止自动读数。

具体分数阈值由灰测数据确定，不能直接写死为生产标准。

## 12. 数据与接口

每次识别保存：

- 原始照片、裁正图和颜色校正图；
- 每个试纸ROI；
- 手机型号、图片参数和拍照时间；
- 操作台、卡纸和试纸批次；
- 图像质量、校正残差和显色时间；
- AI第一候选、第二候选和置信度；
- 用户确认值；
- 后台复核真值；
- 算法、颜色模型和业务规则版本。

AI值、用户值和后台真值分开保存，禁止覆盖。

## 13. 标定数据

### 13.1 原型阶段

每个项目每个色阶建议至少收集30条真实反应试纸，覆盖：

- 至少2个试纸批次；
- 至少5款手机；
- 有效显色窗口的前、中、后时间点；
- 正常、偏暖、偏冷和轻度阴影；
- 多名操作人员。

原型数据只用于验证路线，不用于宣称正式准确率。

### 13.2 上线验证阶段

- 每个色阶建议累计100条以上有效样本。
- 至少3个独立试纸批次。
- 训练集和测试集按批次或采集日期隔离。
- 关键合格边界增加样本量。
- 真值由标准溶液、国标方法或校准仪器确认。

真实锅炉水样用于验证干扰和现场适应性，不能替代标准溶液标定。

## 14. 灰测验收目标

以下为建议工程目标：

- 四角定位成功率不低于99%。
- 合格照片中必测槽位识别率不低于99%。
- 离散色阶完全一致率不低于90%。
- 允许相邻一档的一致率不低于98%。
- 关键合格边界异常检出率不低于95%。
- 低置信度样本错误自动确认率低于1%。
- 支持手机型号内重复拍摄结果保持在同一色阶或约定误差内。

正式指标需要专业人员结合风险和样本量批准。

## 15. 12周实施计划

### 第1-2周：化学和产品冻结

- 确定试纸厂家、型号、色阶和批次。
- 确定7项操作时间和共同拍照窗口。
- 确定磷酸根、亚硫酸根启用逻辑。
- 冻结操作台功能布局。

### 第3-4周：硬件打样

- 完成纸质、硬板和拍照罩样机。
- 验证四角码尺寸、试纸槽和手机画面。
- 制作第一批可数字化校准卡纸。

### 第5-7周：算法基线

- 完成ArUco、透视校正和质量门禁。
- 完成一阶空间颜色校正。
- 完成ROI提取和离散色阶识别。

### 第8-9周：小程序和后台

- 增加项目计时、拍照检查、候选确认。
- 增加操作台、卡纸、试纸批次字段。
- 后台增加ROI和样本真值审核。

### 第10-12周：灰测验收

- 完成多手机、多批次和多环境测试。
- 统计每项目混淆矩阵和重拍率。
- 先开放达到目标的项目。
- 保留人工录入作为稳定兜底。

## 16. 团队配置

- 项目经理：计划、试纸、客户灰测和验收闭环。
- 水处理专业人员：项目选择、标准方法和药剂方案。
- 视觉算法工程师：定位、颜色校正、色阶模型和评估。
- 小程序工程师：计时、拍照、确认和交互。
- 后端工程师：识别服务、数据结构、规则和审计。
- 工业设计/印刷供应商：操作台、拍照罩和色卡生产。

## 17. 开工前必须取得的资料

1. 7种试纸的品牌、型号和实物。
2. 每种试纸完整比色卡及数值范围。
3. 每种试纸操作说明和显色时间窗口。
4. 至少2个生产批次试纸。
5. 标准溶液或可靠参考检测方法。
6. 药剂方案样本和锅炉档案样本。
7. 首批重点支持手机型号清单。

在以上资料没有准备完成前，可以开发拍照和定位框架，但不应承诺最终读数准确率。

## 18. 需要确认的产品决策

1. 操作台设置7个正式槽位，不保留空槽。
