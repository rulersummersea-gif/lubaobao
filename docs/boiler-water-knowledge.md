# 工业锅炉水质知识体系

> 本文档用于炉保保项目的产品设计、后台标准配置、巡检结果解释、培训材料和后续规则引擎建设。  
> 涉及 GB/T 1576 工业锅炉水质的具体数值时，当前作为产品灰测参考；正式上线前应以正版标准原文、锅炉额定压力、锅炉类型和现场水处理方案复核。

## 1. 学习总框架

工业锅炉水质不是单个指标问题，而是围绕锅炉安全、能效和维护成本形成的一套风险控制体系。

学习顺序建议如下：

| 层级 | 学习内容 | 目标 |
|---|---|---|
| 1 | 锅炉系统基础 | 知道给水、锅水、蒸汽、排污分别是什么 |
| 2 | 水质指标 | 理解每个指标测什么、为什么测 |
| 3 | 风险机理 | 知道结垢、腐蚀、汽水共腾如何发生 |
| 4 | 国标体系 | 理解 GB/T 1576 按锅炉类型、压力段、水样类型分类 |
| 5 | 现场检测 | 建立试纸优先的现场检测流程 |
| 6 | 系统落地 | 转成标准表、异常判断、维护建议和月报 |

## 2. 锅炉水系统基础

### 2.1 水在锅炉系统里的路径

| 名称 | 位置 | 作用 | 重点风险 |
|---|---|---|---|
| 原水 | 进入水处理设备前 | 自来水、地下水、河水等来源水 | 硬度、悬浮物、氯离子、碱度波动 |
| 补给水 | 经过软化/除盐后的水 | 补充系统损失 | 硬度超标会导致结垢 |
| 给水 | 进入锅炉前的水 | 送入锅炉参与蒸发 | 溶解氧、硬度、pH、铁、油 |
| 锅水/炉水 | 锅筒或锅壳内的水 | 被加热、浓缩并产生蒸汽 | 结垢、腐蚀、汽水共腾 |
| 蒸汽 | 锅炉输出 | 供生产或换热使用 | 携盐、带水、蒸汽品质下降 |
| 凝结水/回水 | 蒸汽冷凝返回 | 节水节能 | 铁、油、pH、污染回流 |
| 排污水 | 连续/定期排出的锅水 | 控制浓缩和泥渣 | 排污不足会浓缩，排污过量会浪费热量 |

### 2.2 为什么锅炉必须管水质

| 风险 | 原因 | 后果 |
|---|---|---|
| 结垢 | 钙镁离子、硅酸盐、铁氧化物沉积 | 传热变差、燃料浪费、管壁过热、爆管风险 |
| 腐蚀 | pH 偏低、溶解氧、氯离子、二氧化碳 | 泄漏、点蚀、氧腐蚀、寿命缩短 |
| 汽水共腾 | 碱度/TDS 过高、负荷波动、排污不足 | 蒸汽带水、携盐、污染用汽设备 |
| 药剂失控 | 磷酸盐、亚硫酸盐等投加不足或过量 | 防垢不足、盐分升高、排污负担变大 |
| 能耗上升 | 结垢和排污策略不合理 | 燃料成本增加、热效率下降 |

## 3. 水样分类

GB/T 1576 这类标准不是只看“炉水六项”，而是按水样位置分类。系统设计时建议至少分三类。

| 分类 | 系统字段建议 | 典型项目 | 产品用途 |
|---|---|---|---|
| 给水/补给水 | `feedwater` | 硬度、pH、溶解氧、铁、油、浊度 | 判断进入锅炉前的水处理质量 |
| 锅水/炉水 | `boiler_water` | pH、碱度、磷酸根、亚硫酸根、溶解固形物 | 判断锅内浓缩、加药、防垢、防腐状态 |
| 企业内控/辅助指标 | `internal_control` | 氯离子、电导率、TDS、浓缩倍数 | 辅助排污、腐蚀风险和趋势管理 |

当前炉保保第一版选择了 6 个现场友好指标：

1. pH
2. 磷酸根
3. 亚硫酸根
4. 总碱度
5. 氯离子
6. 硬度

需要注意：

| 项目 | 更准确的归类 | 说明 |
|---|---|---|
| pH | 锅水/给水都可测 | 位置不同，标准范围不同 |
| 磷酸根 | 锅水 | 主要判断锅内防垢药剂余量 |
| 亚硫酸根 | 锅水 | 主要判断除氧剂余量 |
| 总碱度 | 锅水 | 与防腐、防垢、汽水共腾有关 |
| 氯离子 | 企业内控/辅助 | 常用于判断浓缩和点蚀风险，不宜简单写成“炉水国标硬限” |
| 硬度 | 更偏给水/补给水 | 炉水中测到硬度有维护意义，但核心管控通常在给水入口 |

## 4. 工业蒸汽锅炉压力段

对“38 公斤以内”的工业蒸汽锅炉，可按额定工作压力 `P` 分段。1 MPa 约等于 10 公斤压力。

| 压力段 | 表示方式 | 约等于公斤压力 | 系统建议编码 |
|---|---:|---:|---|
| 低压一段 | P ≤ 1.0 MPa | ≤10 kg | `steam_p_le_1_0` |
| 低压二段 | 1.0 < P ≤ 1.6 MPa | 10-16 kg | `steam_p_1_0_1_6` |
| 中低压段 | 1.6 < P ≤ 2.5 MPa | 16-25 kg | `steam_p_1_6_2_5` |
| 中压前段 | 2.5 < P < 3.8 MPa | 25-38 kg | `steam_p_2_5_3_8` |

系统规则建议：

| 规则 | 说明 |
|---|---|
| 锅炉档案必须保存额定压力 | 没有压力，就无法自动匹配标准段 |
| 标准表按压力段配置 | 同一检测项可以有多条压力段标准 |
| 识别时按锅炉压力匹配 | 先找锅炉额定压力，再找对应标准 |
| 未匹配时给出提示 | 不应静默使用错误标准 |

## 5. 锅水常见控制项目

以下表格用于理解炉水/锅水检测项目的意义。具体标准值需按标准原文和现场条件复核。

| 项目 | 常见单位 | 主要意义 | 偏低风险 | 偏高风险 | 维护动作 |
|---|---|---|---|---|---|
| pH | 无量纲 | 判断酸碱性，防腐蚀基础指标 | 酸腐蚀、保护膜不稳定 | 碱腐蚀、汽水共腾风险 | 复测，检查加药泵和碱性药剂 |
| 总碱度 | mmol/L | 判断锅水缓冲和碱性物质总量 | 防腐能力不足 | 起泡、汽水共腾、排污不足 | 调整加药和排污频率 |
| 酚酞碱度 | mmol/L | 反映部分碱度组成 | 碱性储备不足 | 过碱、共腾风险 | 与总碱度联合判断 |
| 磷酸根 | mg/L | 判断防垢药剂余量 | 防垢不足，钙镁不易转化泥渣 | 药剂过量、盐分升高 | 调整磷酸盐投加，观察排污 |
| 亚硫酸根 | mg/L | 判断除氧剂余量 | 氧腐蚀风险升高 | 盐分增加、排污负担变大 | 检查除氧器和除氧剂投加 |
| 溶解固形物/TDS | mg/L | 判断浓缩程度 | 通常不是偏低问题 | 携盐、共腾、排污不足 | 增加连续或定期排污 |
| 电导率 | μS/cm | 快速反映离子总量 | 通常不是偏低问题 | 浓缩、盐分高 | 作为排污控制参考 |
| 氯离子 | mg/L | 辅助判断浓缩和点蚀风险 | 通常不是偏低问题 | 点蚀、浓缩过高 | 加强排污，检查补水来源 |
| 硬度 | mmol/L | 判断钙镁离子残留 | 通常不是偏低问题 | 结垢风险 | 检查软水器、树脂、再生盐 |

## 6. 当前 6 项指标详解

### 6.1 pH

pH 是锅水酸碱性的基础指标。锅水通常需要保持偏碱性，以减少酸性腐蚀并维持金属表面保护状态。

| 判断 | 可能原因 | 维护建议 |
|---|---|---|
| pH 偏低 | 加药不足、补水异常、酸性污染、读数误差 | 复测，检查加药泵、药箱浓度和补水 pH |
| pH 偏高 | 碱性药剂过量、排污不足、浓缩倍数高 | 降低加药，加强排污，联看碱度/TDS |

产品提示语建议：

> pH 偏离正常范围时，应先复测确认；若持续偏低，优先检查加药系统和补水水质；若持续偏高，应关注碱度、TDS 和汽水共腾风险。

### 6.2 磷酸根

磷酸根用于判断磷酸盐防垢药剂余量。它帮助钙镁离子形成较易排出的泥渣，降低硬垢风险。

| 判断 | 可能原因 | 维护建议 |
|---|---|---|
| 磷酸根偏低 | 防垢药剂投加不足、硬度冲击、排污过大 | 补加磷酸盐药剂，复测硬度和磷酸根 |
| 磷酸根偏高 | 药剂过量、排污不足 | 减少投药，加强排污，避免盐分升高 |

### 6.3 亚硫酸根

亚硫酸根通常反映除氧剂余量，用于消耗残余溶解氧，降低氧腐蚀风险。

| 判断 | 可能原因 | 维护建议 |
|---|---|---|
| 亚硫酸根偏低 | 除氧剂不足、除氧器异常、补水含氧高 | 检查除氧设备和投药量，缩短复测周期 |
| 亚硫酸根偏高 | 除氧剂过量 | 减少投药，关注盐分增加和排污负担 |

### 6.4 总碱度

总碱度反映锅水中碱性物质总量。它既有防腐、防垢作用，也与汽水共腾风险有关。

| 判断 | 可能原因 | 维护建议 |
|---|---|---|
| 总碱度偏低 | 加药不足、排污过大、补水异常 | 适当补加碱性药剂，联看 pH |
| 总碱度偏高 | 排污不足、浓缩倍数高、加药过量 | 加强排污，降低加药，联看 TDS/电导率 |

### 6.5 氯离子

氯离子是非常有用的现场辅助指标，常用于判断浓缩程度、补水来源变化和点蚀风险。

| 判断 | 可能原因 | 维护建议 |
|---|---|---|
| 氯离子偏高 | 排污不足、补水氯离子高、浓缩倍数过高 | 加强排污，检查补水来源和软化/除盐系统 |

系统表述建议：

> 氯离子建议在系统中标为“企业内控/辅助判断指标”，用于排污和腐蚀风险管理；不要简单写成“锅水国标硬性六项”。

### 6.6 硬度

硬度反映水中钙镁离子含量。硬度最重要的检测位置通常是补给水/给水，因为钙镁进入锅炉后会形成结垢风险。

| 判断 | 可能原因 | 维护建议 |
|---|---|---|
| 硬度偏高 | 软水器失效、树脂再生不足、旁通漏水、原水硬度冲击 | 检查软水器、再生盐、树脂状态，复测给水硬度 |

系统表述建议：

> 硬度偏高是结垢风险的重要信号，应优先检查软化设备和补水水质；若锅水中也检出硬度异常，应考虑停炉检查受热面沉积。

## 7. 风险机理图谱

### 7.1 结垢风险

| 触发信号 | 解释 | 优先动作 |
|---|---|---|
| 硬度偏高 | 钙镁离子进入系统 | 查软水器、补水硬度 |
| 磷酸根偏低 | 防垢药剂余量不足 | 调整防垢药剂 |
| 排污不足 | 泥渣和盐分不易排出 | 增加排污 |
| 受热面温度异常 | 可能已有垢层 | 安排检查和清洗评估 |

### 7.2 腐蚀风险

| 触发信号 | 解释 | 优先动作 |
|---|---|---|
| pH 偏低 | 酸性腐蚀风险增加 | 调整碱性药剂 |
| 亚硫酸根偏低 | 除氧剂不足，氧腐蚀风险增加 | 检查除氧器和投药 |
| 氯离子偏高 | 点蚀风险增加 | 加强排污，查补水来源 |
| 回水铁高 | 管网腐蚀或污染 | 检查回水系统 |

### 7.3 汽水共腾风险

| 触发信号 | 解释 | 优先动作 |
|---|---|---|
| 总碱度偏高 | 起泡和共腾风险增加 | 加强排污，降低加药 |
| TDS/电导率偏高 | 锅水浓缩过高 | 调整连续排污 |
| 负荷波动大 | 容易带水 | 稳定负荷，检查水位控制 |

## 8. 试纸优先的现场检测方法

炉保保第一阶段的产品边界是“低门槛、长者友好、现场可执行”。因此检测方法应坚持试纸优先：能用试纸完成趋势判断和风险筛查的项目，尽量不用滴定和仪表作为必选动作。

滴定和仪表可以保留为复核方式、第三方检测方式或后续高级版能力，但不应成为小程序日常巡检的刚性流程。

### 8.1 当前产品优先检测项

| 项目 | 试纸可行性 | 第一阶段推荐方式 | 优先级 | 产品定位 | 说明 |
|---|---|---|---:|---|---|
| pH | 高 | pH 试纸 | 1 | 必选 | 快速、便宜、容易教学；颜色判断有误差，异常时复测 |
| 磷酸根 | 中 | 磷酸根试纸 | 2 | 必选 | 用于判断防垢药剂余量，适合做区间判断 |
| 亚硫酸根 | 中 | 亚硫酸根试纸 | 3 | 必选 | 用于判断除氧剂余量，取样后应尽快检测 |
| 总碱度 | 中 | 总碱度试纸 | 4 | 必选 | 用于判断锅水碱度趋势；需要接受粗精度 |
| 氯离子 | 中 | 氯离子试纸 | 5 | 必选/内控 | 用于辅助判断浓缩和排污，不作为强合规硬限 |
| 硬度 | 高 | 硬度试纸 | 6 | 必选 | 更适合测补给水/给水，用于发现软水器失效 |

### 8.2 暂不作为第一阶段必选的项目

| 项目 | 常见检测方式 | 第一阶段策略 | 原因 |
|---|---|---|---|
| 酚酞碱度 | 滴定 | 暂不必选 | 现场操作复杂，和总碱度对普通巡检员解释成本高 |
| 溶解固形物/TDS | TDS 仪/实验室 | 暂不必选 | 需要仪表，维护和校准增加负担 |
| 电导率 | 电导率仪 | 暂不必选 | 需要仪表，适合后续排污优化模块 |
| 溶解氧 | 仪表/试剂 | 暂不必选 | 检测要求高，现场试纸化难度较大 |
| 铁、油、浊度 | 试剂/仪表/实验室 | 暂不必选 | 更适合专项检查或第三方检测 |

### 8.3 试纸方案的产品原则

| 原则 | 说明 |
|---|---|
| 试纸用于风险筛查 | 试纸结果用于发现异常趋势，不直接替代法定检测 |
| 异常先复测 | 单次异常先提示复测，避免颜色误判导致错误维护 |
| 看组合风险 | 不只看单项超标，应看硬度、磷酸根、pH、亚硫酸根、碱度、氯离子的组合 |
| 允许粗精度 | 后台标准应支持区间值和颜色档位，不强求小数级精度 |
| 文案要保守 | 用“建议范围”“风险提示”“建议复测”，少用“合格/不合格” |
| 保留复核入口 | 对重大异常，可提示“建议用滴定/仪表或第三方检测复核”，但不强制 |

取样注意事项：

| 要点 | 说明 |
|---|---|
| 取样要冷却 | 高温样品会影响读数，也有安全风险 |
| 先冲洗取样管 | 避免管内旧水影响结果 |
| 尽快检测亚硫酸根 | 暴露空气后结果可能变化 |
| 颜色读数要统一 | 建议固定光线和读数时间 |
| 异常必须复测 | 试纸异常不能直接作为最终处置依据 |

## 9. 系统设计建议

### 9.1 标准表设计

建议标准表保留以下字段：

| 字段 | 说明 |
|---|---|
| item_code | 检测项目编码 |
| item_name | 检测项目名称 |
| sample_type | 水样类型：给水/锅水/内控 |
| boiler_type | 锅炉类型：蒸汽锅炉/热水锅炉等 |
| pressure_min_mpa | 适用压力下限 |
| pressure_max_mpa | 适用压力上限 |
| min_value | 标准下限 |
| max_value | 标准上限 |
| unit | 单位 |
| display_range | 前端显示范围 |
| standard_source | 标准来源 |
| standard_note | 备注 |
| enabled | 是否启用 |
| updated_at / updated_by | 审计字段 |

### 9.2 识别判断逻辑

建议判断顺序：

1. 获取巡检记录。
2. 获取锅炉档案。
3. 读取锅炉额定压力。
4. 按 `item_code + sample_type + boiler_type + pressure_range` 匹配标准。
5. 若检测值低于下限或高于上限，标记为 `warning`。
6. 若缺少标准，标记为 `unknown` 或提示“未配置标准”。
7. 根据异常组合生成维护建议。

### 9.3 异常组合建议

当前系统第一阶段只对锅水/炉水 6 项做组合诊断，不采集给水数据。给水/补给水会在后续版本作为独立水样类型扩展。

现场端处理意见只保留可执行动作：复测、排污、加药、药箱/加药泵/软水器基础检查。连续异常、方案复核、专业处置只作为后台服务支持提醒，由平台服务人员确认后再反馈客户。

| 异常组合 | 风险判断 | 建议 |
|---|---|---|
| 硬度高 + 磷酸根低 | 结垢风险高 | 检查软水器，补加防垢药剂 |
| pH 低 + 亚硫酸根低 | 腐蚀风险高 | 检查除氧剂和碱性药剂 |
| 氯离子高 + 碱度高 | 浓缩过高 | 加强排污，复测 |
| 磷酸根高 + 亚硫酸根高 | 药剂过量可能 | 降低投药，关注排污 |
| pH 高 + 碱度高 | 共腾风险 | 降低加药，加强排污 |

## 10. 产品文案原则

面向长者友好和现场人员，文案应避免过度学术化。

| 不建议 | 建议 |
|---|---|
| “该指标不符合 GB/T 1576 限值” | “该项偏离建议范围，建议复测并检查加药/排污” |
| “存在氧腐蚀、碱脆等复杂风险” | “可能增加腐蚀风险，请检查除氧剂和 pH” |
| “TDS 与电导率呈线性近似关系” | “盐分偏高时，通常需要加强排污” |
| “硬度阳离子导致沉积” | “硬度偏高容易结垢，先检查软水器” |
