## 2. 要解决的问题：手机比色为什么不准

论文对误差来源的论述（Introduction + 相关工作）：

1. **非线性成像过程（non-linear image formation）**：手机传感器输出到最终 sRGB 图像经过黑电平、白平衡、gamma、色调映射等一系列自动处理（原文概括为"non-linear image formation process"），同一物体在不同设备/不同自动参数下 RGB 不一致。**论文没有单独逐项展开 gamma/曝光建模**，而是把"设备色调差异 + 光照"打包成一个待校正的失真函数，用参考色板实测拟合掉。
2. **环境光照不可控**：色温（实验用了 2800K/4000K/6500K 三档）、光照方向、强度不均、阴影，导致同一张板子上不同位置的颜色失真程度不同——这是本文最核心的论点：**全局单一校正式不够，校正系数必须随空间位置变化**。
3. **非朗伯反射（non-Lambertian reflectance）**：已有方法假设被测物为理想漫反射（朗伯面），实际表面有镜面反射分量；拍摄角度不一致时反射贡献不同，引入误差。论文的解法不是建模反射，而是**用 AR 把拍摄角度固定住**，使反射条件一致。
4. **已有方案的不足**（论文对三条路线的批评，对我们的选型有直接参考价值）：
   - Kong et al.（闪光灯为主光源 + 黑白背景重标定）：LED 不是主光源时失效，且手动对齐/取背景色等操作步骤多，人为误差大。
   - Nixon et al.（闪光灯开/关两张配对相减去环境光 + 离散色卡做传感器标定）：需要完美对齐的两张照片；其"传感器三通道响应随强度线性"的假设过强，论文实测该方法 mRMSE 高达 67.86（远差于其他方法，见 §4）。
   - Solmaz et al.（机器学习分类）：只能输出离散类别、不能给连续值，且有泛化问题。
5. **离散色卡（color checker）的固有缺陷**：离散色块只做"多图之间的相对校正"，缺乏对颜色空间的连续覆盖，可能产生有偏结果（"lack of continuous observation"）；且全局一套系数无法处理板面不同位置光照不一致——论文比喻其方案相当于"在空间上摆了无数个 color checker，各自用不同校正系数"。
6. **人眼读数误差**：个体颜色感知差异（论文引文献 [12–14]），这是其产品价值的对照基线。

## 3. 系统方案（可复现颗粒度）

系统三模块：① 参考色板（board）→ ② AR 引导拍照（capture）→ ③ 颜色校正（correction）。

### 3.1 参考色板设计

- **四角 ArUco 码**：选 ArUco 的理由（原文四条）：黑白图案对视角/光照不均鲁棒；每个码二进制编码唯一可区分四个角（可判方向）；编码有冗余、部分遮挡仍可检出；OpenCV 开源可用。
- **色条布局**：四条色条沿板子四边布置，中央区域放被测样本（试纸）。
- **色条内容——在 HSV 空间做连续采样**，覆盖可见光谱约 380–700nm：
  - 顶、底两条：**Hue 渐变**，`H ∈ [0,1] 等间隔采样，S=1, V=1`；
  - 左侧条：**Saturation 渐变**，`H ∈ [0,1], S ∈ [0,1], V=1`；
  - 右侧条：**Value 渐变**，`H ∈ [0,1], S=1, V ∈ [0,1]`。
- **为什么选 HSV 而不是 CIE-Lab**（原文明确论证）：Lab 感知更线性且覆盖全色域，但其中"计算机图像处理真正可用的部分"三维几何形状不规则，难以用板子上有限色条采样覆盖；HSV 是规则的圆锥几何，能用有限板面采样点包住全部有用颜色空间，且接近人眼读色方式。其余颜色被假设为边界采样点的"稳定线性组合/插值"。
- **打印色失真的处理（关键工程细节）**：打印稿实际颜色与设计文件显著不同（论文 Fig 3A vs 3C 对比）。作者**不建模打印机失真**，而是：把打印出来的板子用手机扫描 App 数字化，**以"数字化后的印刷板颜色"作为标准参考值**（中间色彩系统），而不是用理论设计值。经验上能适应不同用户的不同打印机。
  - 注意：这意味着"标准值"本身不是光谱学意义上的真值，而是自洽的参考系。绝对精度靠这个自洽参考系 + 逐拍摄校正共同保证。

### 3.2 AR 引导拍照模块

目标：把每次拍摄姿态约束到同一个最优位姿，消除角度不一致带来的非朗伯效应。

**(1) 标记跟踪子模块（marker tracking）**
- 检测 4 个 ArUco 码的 4 个角点，共最多 16 个关键点（位姿解算最少只需 3 点，16 点提供冗余）。
- 性能优化：不对每帧做 ArUco 全检测，首帧检测后用**金字塔 Lucas-Kanade 光流（PLK）**跟踪（30fps 下相邻帧仅 33ms，像素级运动小）；跟踪失败（出界/剧烈运动）才重新检测；只有 16 点全部检出时才启用 PLK 跟踪。效果：25fps → 60fps（提升 140%）。

**(2) 位姿解算子模块（pose solver）**
- 世界坐标系：原点定在色板左下角，x 右、y 上，板面在 XOY 平面。
- 针孔模型（原文 Eq 1）：

  ```
  s · [P_i; 1] = K · R · (P_i^w − C)
  ```

  其中 `P_i` 图像点（R²）、`P_i^w` 世界点（R³）、`K` 相机内参（3×3）、`R` 旋转（3×3）、`C` 世界系下相机中心（平移）、`s` 尺度因子。
- 内参 K：直接用手机厂商 SDK 提供的标定矩阵与内置镜头畸变校正（Apple AVCameraCalibrationData / Android CameraCharacteristics），不自行标定。作者明确说更复杂的非线性模型"偶尔更好但不具泛化性、会拟合噪声"。
- 用 **PnP 算法**（≥3 对 2D-3D 点）解 R、C。

**(3) AR 引导子模块（gating，最终把关者）**
- **最优姿态定义：相机与板面平行、正上方俯视（90° 视角）**。早期工作（Nixon et al.）推荐 45°（配合侧向闪光灯抑制镜面反射）；论文不用闪光灯，仿真证明在朗伯假设下 90° 精度单调最优且分辨率最高（见 §4.2）。
- **最优拍摄高度（原文 Eq 2，相似三角形）**：

  ```
  focal / optimal_height = min( W_image / W_board ,  H_image / H_board )
  ```

  `focal` 为像素单位焦距，`W/H_image` 图像宽高（px），`W/H_board` 板子物理宽高（世界单位），所得高度为世界单位。即：让板子恰好铺满画面的最小边所对应的高度。
- **容差（acceptance region）**：水平方向最优点周围 ±20px；高度方向允许最优高度的 1.0–1.5 倍。
- **交互流程**：画面中央黄色箭头指示应移动方向与距离（越接近箭头越短）→ 屏幕四角红框对齐 4 个 ArUco 码调高度 → 达标后红框变绿 → 提示保持 1 秒 → **自动快门**。另提供文字与语音引导（无障碍）。拍后**自动裁剪板外内容（隐私）并拉正为正交视图**。

### 3.3 颜色校正算法（核心）

**(1) 简单线性模型（基线，原文 Eq 3）**——传统 color checker 的方法，全局一套系数：

```
I_ref^c = α_c · I_image^c + β_c + ε,   c ∈ {R, G, B}
```

**(2) 空间变系数模型 SVCM（本文方案，原文 Eq 4）**——系数是像素位置的函数，建模板面上光照的方向/强度不均：

```
I_ref^c(x,y) = α_c(x,y) · I_image^c(x,y) + β_c(x,y) + ε,   c ∈ {R, G, B}
```

- `α_c(x,y)`、`β_c(x,y)` 各用一个**一阶或二阶二维多项式曲面**拟合（原文 Fig 7）：
  - 一阶（论文最终采用）：`f1(x,y) = a·x + b·y + c`，3 参数；
  - 二阶：`f2(x,y) = a·x² + b·xy + c·y² + l·x + m·y + n`，6 参数。
- 选一阶的理由：板子物理尺寸小，光照变化可用一阶平面近似；低阶更鲁棒、不易过拟合。
- **拟合方法：普通最小二乘 OLS，R/G/B 三通道各自独立拟合一套（α,β 曲面）**。所以每张图共拟合 6 个一阶曲面（3 通道 × α/β）。
- **观测对采样方式**：在拍摄图像的色条上与其在标准参考板上的对应位置，**按 10 像素间隔采样配对点，共 424 对**，每对给出（观测 RGB，参考 RGB，位置 x,y）。以 (x,y) 为自变量、以"参考值/观测值关系"为目标拟合 OLS。
- **应用**：把拟合出的 3 组 α(x,y)、β(x,y) 应用到整图所有像素，逐像素、逐位置地完成校正。直觉理解：α 曲面吸收"光照强度/增益的空间变化"，β 曲面吸收"色偏/黑电平的空间变化"；色条提供了全 HSV 空间的锚点，使映射在整个颜色空间内有效而非只在灰轴附近。

**(3) 评价指标（原文 Eq 5）**：RGB 三通道 RMSE 的均值 mRMSE：

```
RMSE_c = sqrt( (1/(W·H)) Σ_x Σ_y ( I_ref^c(x,y) − I_corr^c(x,y) )² )
mRMSE  = (1/3) Σ_{c∈{R,G,B}} RMSE_c
```

选 RMSE 而非 MAPE 的理由：MAPE 对不同颜色值有偏（小值被放大），RMSE 度量绝对差异。

**(4) 读数算法（pH 场景，我们可直接照搬的思路）**：
- 校正后，在 **CIE 1931 XYZ 色度坐标 (x, y)** 上工作（遵循比色试纸文献惯例 [21,45]）。
- 由比色卡的离散色块构建参考曲线（卡上每档 pH → 一个 (x,y) 点，连成曲线）。
- 试纸实测色度点通常不恰好落在曲线上：找到色度距离最近的两个参考点，用**反距离加权 IDW** 插值读数。原文示例（Fig 15）：

  ```
  最近两档 pH = 6.8 和 7.0，色度距离 d1、d2
  measured pH = (6.8 × d2 + 7.0 × d1) / (d1 + d2)
  ```

  即可读出超越比色卡档位分辨率（0.2–0.4）的连续值。
- "免比色卡"模式（color chart free）：比色卡可预先在另一种光照下拍照、校正后数字化存进 App，厂家不必随试纸附实体比色卡——**校正算法使"跨光照的绝对比色"成为可能**，这是该系统最有产品价值的特性。

## 4. 实验与结论数据

### 4.1 仿真：色条图案 × 校正模型组合（Fig 10）

- 设置：44×24 随机颜色马赛克（每格采 1 像素）做被测对象；3 种色温（2800K/4000K/6500K）× 3 种光照方向，共 9 组渲染，取平均 mRMSE。
- 变量 A：4 种色条图案——(A) Hue+Saturation+Value 全配（最终方案）；(B) 无 Saturation 条；(C) 无 Value 条；(D) 无 Hue 条。
- 变量 B：4 种校正模型——一阶 SVCM、二阶 SVCM、简单线性模型（无空间变系数）、直方图匹配（非参数）。
- **结果：图案 (A) + 一阶 SVCM 最优，mRMSE = 12.86**（0–255 灰度量纲，下同）。所有模型在图案 (A) 上普遍最好；直方图匹配整体最差且不稳定。参数模型在 (A) 与 (D) 上接近、(D) 略优 → **Hue 通道信息量最低**（对校正贡献最小）。
- 注意：论文只给出一处 mRMSE 数字（12.86），其余组合只有 Fig 10 柱状图，无逐格数值表。

### 4.2 仿真：最优拍摄角度（Fig 11）

- 视角 35°–90°，步长 5°，朗伯面假设，看 mRMSE 随角度变化。
- **结果：精度随视角趋近 90°（正俯视）几乎单调提升** → 支撑 AR 引导采用 90° 而非文献中的 45°。注意该结论在朗伯假设下仿真得出，对强镜面反射表面 45°+侧光仍有物理依据。

### 4.3 实物：与其他比色方法对比（Table 1）

荧光灯实验室环境、iPhone SE2（未考察多设备），评价点为色板自身颜色（标准值取数字化印刷板）：

| 方法 | mRMSE |
|---|---|
| Color checker 校正（同一板子上模拟 24 点离散色卡 + 全局线性） | 13.93 |
| Flashlight rescale（Kong et al.，闪光灯+黑白重标定） | 14.48 |
| Flashlight color checker correction（Nixon et al.，闪光灯差分+RGB→XYZ 映射，去掉了其 INUC 步骤） | 67.86 |
| **本文（一阶 SVCM）** | **13.41** |

结论：本文方法最低；Nixon 方案大误差归因于"三通道响应随强度线性"假设不成立；闪光灯类方法还有手动选黑白参考点等操作负担。注意差距（13.41 vs 13.93）不大，**SVCM 的相对优势主要体现在光照不均场景**；Table 1 的单一均匀荧光灯场景其实弱化了其优势。

### 4.4 实物：设备无关性（Fig 12–13）

- 两部手机（iPhone SE 2nd gen 2020 / iPhone XSMAX 2018）× 15 种光照条件，拍一排彩色长尾夹。
- 校正前 vs 校正后逐夹算 15 张图的颜色方差：**校正后颜色方差最多缩小约 15 倍**（摘要口径为"reduce up to 90% color variance"，Fig 13 正文口径为"up to a factor of 15"——两处表述不同，引用时以正文 Fig 13 为准）。
- 改善幅度与颜色本身相关：粉色夹改善小，因为校正前方差本来就小。

### 4.5 实物：pH 试纸读数 vs 人眼（Table 2，产品级结论）

- 6 种 pH 缓冲液（3.00 / 6.86 / 7.00 / 7.80 / 9.00 / 9.18，Orion 5-Star 电极仪标定），3 种 pH 试纸+比色卡（量程 3–5.5 / 6–8 / 8–9.5，Fisher Scientific），iPhone SE2 拍摄，6 名 18–40 岁无自报色觉障碍受试者人眼读数对照。
- 两种场景（MAE，单位 pH）：

| 场景 | 不校正 | 校正后 | 人眼 |
|---|---|---|---|
| Reference case（试纸与比色卡同光照同图拍摄） | 0.12 | 0.12 | **0.37** |
| Color chart free（比色卡室外阳光、试纸室内，分开拍） | 0.15 | **0.12** | — |

- 逐点细节（Table 2）：人眼在卡上有明确档位的溶液上读得准（3.00/6.86/7.00），在超出卡分辨率的点上明显变差（9.18 处人眼 +0.67，算法 0.00；9.00 处人眼 +0.45，算法 −0.15）。
- **结论三条**：① 算法 MAE 0.12，约为肉眼（0.37）的 3 倍精度（摘要中"200% better"即指 0.37→0.12）；② IDW 插值能读出比色卡档位之间的连续值；③ 跨光照成立 → 厂家可不必附实体比色卡，数字化比色卡内置 App。
- 本实验经俄亥俄州立 IRB 批准（2022E0482）。

### 4.6 被证明影响最大的因素（论文证据汇总）

1. **色条对颜色空间的覆盖完整性**：全 HSV 覆盖（A）稳定优于缺任一维度的图案（§4.1）。
2. **校正系数的空间变化性**：SVCM > 全局线性，尤其在光照不均时（§3.3/4.3 论述）。
3. **拍摄角度一致性**：视角越接近 90° 越准（§4.2），AR 引导固定姿态是系统不可分割的一部分而非锦上添花。
4. **"传感器线性响应"假设是危险的**：Nixon 方案 mRMSE 67.86 的教训（§4.3）。
5. 模型阶数不是越高越好：一阶 SVCM ≥ 二阶（二阶易过拟合，§3.3 论述；Fig 10 佐证）。

## 5. 对炉保保的落地建议

我们的现状：A4 横向操作台（四角 ArUco DICT_4X4_50、8 固定槽位、左右对称灰阶 2×5 + 底部 9 个基础/定制色块 = 14 个参考色块），`rectify.py` 透视拉正到 1600×1100 后坐标写死。逐条建议：

**(1) 拍照约束：把论文的 AR 引导降级为"小程序端姿态校验"，成本低、收益大。**
- 我们已有 4 个 ArUco 码 = 16 个角点，做 PnP 位姿解算的全部输入都齐了。微信小程序内可用 camera 组件实时帧 + 轻量检测（或拍照后检测），计算相机相对板面的俯仰/偏航角与高度，**超出容差直接拦截要求重拍**（对接已有的"照片质量检查与不合格拦截逻辑"）。
- 目标姿态按论文结论取 **90° 正俯视**；高度容差参考论文的 1.0–1.5 倍最优高度（Eq 2 可直接算：我们板子 297×210mm、目标铺满 1600×1100，按手机焦距换算出建议拍摄距离，UI 提示"距台面约 XX cm"）。
- 不必做实时箭头 AR（论文 iOS 原生 + 光流跟踪 60fps 那套），拍照后服务器端校验姿态 + 左右灰阶对称性即可覆盖大部分风险。
- **冲突点（轻微）**：论文 90° 结论在朗伯假设下仿真得出。我们的试纸和覆膜打印稿可能有轻微反光，建议实测一次：同一板子在 90° 与 45° 各拍若干张，比较槽位 ROI 的镜面高光出现率，再决定是否坚持 90°。预计 90° 可用（我们不用闪光灯，环境光高光源分散）。

**(2) 色卡方案：14 个离散色块对论文方法而言不够，但不要推倒重来——分两步走。**
- 论文 §4.1 明确证明：连续渐变条（HSV 三维全覆盖）优于部分覆盖；而我们目前是 10 个灰阶 + 6 个基础色 + 3 个定制色共 19 个离散点（去重镜像后有效独立点约 14 个），且**完全缺失 Saturation/Value 维度的连续采样**。直接照搬 SVCM，424 对观测点我们只有 ~14 对，拟合 6 个一阶曲面（每曲面 3 参数 × 6 = 18 个自由参数）处于欠定边缘，外推到试纸颜色区域不可靠。
- **建议的演进路线**：
  - V1（不必改版印刷稿）：用现有 14 色块先拟合**简单线性模型（Eq 3，每通道 α/β 两参数，14 点拟合 6 参数，自由度充足）**；左右灰阶对称性继续做光照不均检测/拦截。先跑通"校正→取色→查标定曲线"闭环。
  - V2（改版印刷稿时）：在四边或空白区增加 **Hue 渐变条（S=1,V=1）与 Value 渐变条**，向论文图案 (A) 靠拢；届时升级到一阶 SVCM。灰阶条保留（它天然是 V 轴在 S=0 处的采样，且对称布置正好给空间变系数提供左右对照）。论文证据显示 Hue 维度信息量最低，板面紧张时可优先保 S、V 渐变。
  - 我们的 3 个定制色块（试纸黄/试纸绿/钼蓝）思路与论文一致且是加分项：在试纸实际显色区域附近加密锚点，插值更准。
- **务必照搬的一条**：参考值不要用设计文件的理论 RGB。按论文做法——**把打印出来的操作台用固定设备/固定光照数字化一次，以实测值作为标准参考**；更稳妥的做法是按批次用分光光度计或同一台校准手机标定并存库（不同打印店/纸张差异真实存在，论文 Fig 3A vs 3C 专门演示了这一点）。

**(3) 读数算法选型：直接采用"色度坐标 + 参考曲线 + IDW 插值"，先不做机器学习。**
- 论文 §3.3(4) 的 pH 读数管线（CIE 1931 xy 色度 → 比色卡参考曲线 → 最近两点 IDW 加权）与我们 8 项试纸读数完全同构，且论文对 ML 分类路线的批评（只能离散、泛化差）对我们成立——我们需要连续浓度值。
- 落地形态：每个检测项（软化水 pH/硬度、炉水 pH/磷酸根/亚硫酸根/总碱度/氯离子/硬度）各建一条"浓度→色度"标定曲线，相当于论文的 color chart 数字化（color chart free 模式），试纸批次标定后存后端，现场拍照校正后查曲线+IDW 出连续读数。这也呼应我们已有的 `test_strip_products`/`test_strip_batches` 批次表设计。
- **警惕 xy 色度的暗部缺陷**：xy = (X/(X+Y+Z), Y/(X+Y+Z)) 丢失亮度信息，深/浅同色相无法区分。若某试纸靠明度变化显色（如硬度、氯离子的深浅变化），应在 xy 之外保留 Y（或用 Lab 的 L*）作为第三维建曲线。论文未讨论此点（其 pH 试纸变色以 hue 为主），**这是我们照搬前必须自己验证的**。

**(4) 训练/标定数据采集方式（论文 §4.5 的实验设计可直接借用）。**
- 标准溶液梯度法：每个检测项配 5–6 档已知浓度标准液（论文 6 个 pH 缓冲液 + 电极仪标定的做法），滴试纸→放操作台→多机型×多光照拍照，同时用仪器真值（pH 计/硬度滴定等）建档。灰测期留存照片本来就是为了这一步。
- 覆盖矩阵参照论文：≥2 档设备差异（论文 2 部 iPhone；我们应覆盖 iOS/安卓/不同价位安卓，国内机型色彩科学差异比两部 iPhone 大得多，**这是论文证据不能直接外推的最大缺口**）× 多档光照（论文 15 种 + 仿真 3 色温×3 方向；我们至少覆盖：室内白光/暖光/窗边自然光/阴天/阴影）。
- 每个批次打印稿留存一张"标定照"（固定设备固定光照），作为该批板的参考值来源。

**(5) 需要警惕的坑（论文显式或隐式给出的教训）。**
- 不要假设传感器 RGB 三通道对强度线性响应（Nixon 方案 67.86 mRMSE 的失败根源）；任何"除法/增益归一化"式白平衡后不再做非线性校验的简化都要实测验证。
- 二阶及以上模型在小板面上是负收益（过拟合），一阶 SVCM 足够；同理我们 V1 用全局线性也足够，不要一上来堆模型复杂度。
- 评价指标用 mRMSE/MAE（绝对量纲），别用 MAPE（对小色值有偏）。
- 直方图匹配类非参数方法在论文对比中垫底且不稳定，不建议采用。
- 论文的"自动裁剪板外内容保护隐私"细节与我们上传留存照片的设计相关：裁剪后上传可顺带脱敏（现场杂物不入户）。
- 闪光灯路线（Kong/Nixon）已被论文证伪其普适性，我们"不开闪光灯 + 环境光 + 参考板校正"的路线与论文一致，保持即可；但要注意低照度场景噪点会吞掉校正收益，照片质量检查里应有亮度/信噪比下限。

## 6. 局限与待验证项

### 论文自身的局限

1. **设备多样性验证薄弱**：实物实验只用 2 部 iPhone（SE2、XSMAX），同厂同年份段，色彩管线相近；安卓碎片化生态未验证（作者把 Android 实现列入 future work）。
2. **光照不均的收益未被充分量化**：Table 1 的对比实验在单一均匀荧光灯下进行，本文方法 13.41 vs 离散色卡 13.93，差距很小；SVCM 宣称的"处理空间光照不均"优势主要靠仿真和 Fig 8 的定性展示，缺一个"强光照不均实物对照实验"的定量数字。
3. **最优角度结论基于朗伯假设仿真**（§4.2 明示），未对真实试纸/覆膜表面的镜面反射做实物角度扫描。
4. **"90% 方差降低"（摘要）与"15 倍方差缩小"（Fig 13 正文）口径不一致**，且均为 up-to 值；改善幅度依赖被测颜色本身。
5. **人眼对照样本小**（n=6、18–40 岁、无色觉障碍），且作者自己指出这低估了人眼误差（全球 2.85 亿视障人群）——"3 倍于人眼"的数字不宜外推为对所有人群的精度承诺。
6. **标准参考系是自洽而非绝对**：参考值来自"手机扫描的印刷板"，不是分光光度计真值；对"绝对颜色"的主张严格说是"对该印刷批次的自洽"。换打印机/纸张批次需重新数字化。
7. **未处理局部阴影**（作者列入 future work）：现场手影、手机自身阴影是一阶曲面模型不了的突变光照。
8. 未讨论曝光/饱和截断：高亮区传感器削顶后任何回归都无法恢复，论文未给操作建议（我们的质量检查需自己加"参考色块无饱和"判定）。
9. iOS 实现细节（Swift/ARKit 层）原文未给出，复现需下 DRYAD 代码。

### 照搬前我们必须自己验证的事

1. **安卓机型覆盖**：至少 3–5 款主流安卓 + 1–2 款 iPhone 重做论文 §4.4 的设备无关性实验（校正前后颜色方差比），确认一阶 SVCM/全局线性在跨生态下仍收敛。
2. **90° vs 45° 实物角度扫描**：在我们真实打印稿 + 真实试纸（含覆膜反光）上做 35°–90° 扫描，验证论文的朗伯仿真结论对我们材质成立。
3. **14 离散色块拟合质量验证**：V1 全局线性模型在 8 种试纸实际显色颜色上的外推误差（用马赛克/实物真值验证）；若某些检测项颜色区域误差大，提前触发 V2 渐变条改版，不要等上线后暴露。
4. **xy 色度 vs Lab/HSV 的读数维度选择**：针对 8 个检测项各自的显色化学（色相主导还是明度主导），逐项验证用哪个色彩空间建标定曲线残差最小。
5. **批次标定流程**：验证"每批打印稿数字化一次作为参考值"的操作成本与精度；若现场打印不可控（用户自行打印），需要设计打印质量准入（我们已有 50mm 标尺核对，需再加色块实测值容差判定）。
6. **低照度/阴影拦截阈值**：一阶模型拟合不了突变阴影，质量检查需有"槽位间光照梯度上限"等指标，阈值需用真实现场照片回归确定。
