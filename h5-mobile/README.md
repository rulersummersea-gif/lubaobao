# 炉保保 H5 灰测端

这是给内测使用的手机 H5 入口，用来先跑通巡检主流程，暂时绕开小程序审核节奏。

## 本地启动

```bash
docker compose -f docker-compose.local.yml up -d --build
```

本地访问：

- H5 手机端：http://127.0.0.1:28082/
- 本地 API：http://127.0.0.1:28080/
- 本地后台：http://127.0.0.1:28081/

H5 默认 API 地址为 `/api`，由本地 nginx 代理到 `lubaobao-local-api:18080`。

## 当前流程

1. 演示登录
2. 选择锅炉
3. 校验材料包
4. 拍照或上传试纸照片
5. 人工录入 6 项炉水读数
6. 提交巡检并生成诊断结果
7. 查看或处理复测任务

## 当前 6 项指标

- pH
- 磷酸根
- 亚硫酸根
- 总碱度
- 氯离子
- 硬度

灰测阶段先保留照片证据并人工录入读数。后续接入照片识别和试纸色卡识别后，可以将人工录入页升级为“识别结果确认页”。
